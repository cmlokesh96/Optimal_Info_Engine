## Execution

All scripts can always be run directly with:

```
python -m scripts.<name>          # e.g. python -m scripts.run_optimal_protocol
```

On macOS/Linux use `python3` instead of `python` if `python` is not on your PATH.

### Using `make`

`make <name>` runs the corresponding script; `make a b c` runs several in sequence; `make list` shows all available script names.

- **Linux**: `make` is preinstalled.
- **macOS**: install the Xcode Command Line Tools once: `xcode-select --install`
- **Windows**: either use a Linux environment like WSL or run directly with `python -m scripts.<name>`

## Structure

The project has the following subfolders:

### parameters
Contains saved parameters characterizing (fitted) normal distributions for other programs to load.

### plots
Save location for plots generated by the programs.

### scripts
Programs that are intended for execution.

### sdesim
Module-like structured library of functions, with functionalities separated into several thematically sorted files.
